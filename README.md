# Grace Book Glow

Build Grace Book with purple/gold glassmorphism design.

Pages:
1. Home - daily verse + Gospel Radio player (play/pause, volume, station selector, LIVE badge)
   Radio stations:
   - K-LOVE: https://maestro.emfcdn.com/stream/k-love/tunein/aac
   - Air1: https://maestro.emfcdn.com/stream/air1/tunein/aac
   - BBN: https://bbnradio-lh.akamaihd.net/i/BBNRadio_1@174570/master.mu3u8

2. Books - grid, FREE badge (green) or price, download PDF/EPUB, "Buy on Apple Books" for paid

3. Courses - cards with YouTube player modal

4. Chat - global chat "grace-chat-global", realtime messages

Design: Deep purple #9333EA, Gold #EAB308, glassmorphism, dark mode, mobile responsive

Use import.meta.env.VITE_* for credentials.

Push to GitHub: grace-book-fixes
